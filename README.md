## ⚡ Background Running & Launching (Kaise Chalayein)

### Option 1: Silent Background Mode (No Black Window) 🌟
- Double-click **`start_background.vbs`** (ya `start_app.bat` me option `2` chuniye).
- App bina kisi command prompt window ke chupchaap background me chalta rahega aur browser me `http://localhost:8000` open ho jayega!
- Jab download khatam hoga, toh aapko Windows Desktop Notification bhi milega!

### Option 2: Stop Background App
- Jab bhi app ko band karna ho, double-click karein **`stop_background.bat`**.

### Option 3: Interactive Launcher Menu
- Double-click **`start_app.bat`**:
  - `[1]` Standard Mode (logs ke sath)
  - `[2]` Silent Background Mode
  - `[3]` Stop Background Server
  - `[4]` Open URL Video Download in Browser
  - `[5]` Exit

## ⚙️ Settings (Settings Kaise Use Karein)

App ke top right me **"Settings"** button par click karke aap:
1. **Download Destination Folder**: Apni pasand ka folder set kar sakte hain, ya **"Default"** button dabakar reset kar sakte hain.
2. **Default Download Quality**: 1080p Full HD, 720p HD, 4K, ya MP3 Audio set karein.
3. **Desktop Notifications**: Background me download khatam hone par Windows popup notification on/off karein.
4. **Auto-Detect Clipboard Links**: URL input box par click karte hi copied link auto-paste ho jayega.
5. **Browser Cookies (Instagram / Facebook)**: Private Instagram stories ya reels download karne ke liye apna browser (Chrome, Edge, Firefox) select karein.
